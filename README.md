# Showroom / SA

Поиск сериалов и шоу в TVmaze. React, Redux Toolkit, TypeScript, Vite и Tailwind CSS; собственный слой запросов без `useQuery`. Интерфейс адаптируется к телефону и управляется с клавиатуры.

## Запуск

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173`). Для запросов и постеров нужен доступ к интернету.

## GitHub Pages

Адрес сайта: [Showroom на GitHub Pages](https://noooopomidor.github.io/tvmaze/). Пример прямой ссылки с запросом, жанром и страницей: [Girls / Comedy / страница 2](https://noooopomidor.github.io/tvmaze/?q=Girls&genre=Comedy&page=2).

GitHub Actions публикует приложение при изменениях ветки `main`. Публикацию также можно запустить вручную: откройте вкладку **Actions**, выберите workflow публикации и нажмите **Run workflow**.

Production-сборка использует базовый путь `/tvmaze/`; локальный `npm run dev` работает от `/`.

## Как работает поиск

- Заголовок Showroom и поле поиска видны всегда. При открытии страницы без `q` в URL список пуст, запросы не отправляются.
- После 350 мс без нового ввода запрос передаётся в TVmaze. Фильтрацию названия и порядок совпадений определяет API.
- Предыдущий запрос отменяется при изменении поискового запроса, очистке или повторной попытке. Поздний ответ не заменяет актуальный; тайм-аут — 12 секунд. Пробелы по краям не вызывают повторный запрос.
- Уникальные жанры собираются из всей выдачи. Фильтрация жанра выполняется перед разбиением по 3 шоу на страницу.
- Изменение запроса или жанра в интерфейсе сбрасывает страницу. «Все жанры» снимает фильтр, повторный клик по выбранному жанру также его снимает.
- Обработаны загрузка, отсутствие совпадений, ошибки сети/API, повтор запроса, отсутствующие и повреждённые постеры. HTML из описаний преобразуется в обычный текст.

## Ссылки на поиск

Запрос, жанр и страницу можно передать в URL: `?q=Girls&genre=Comedy&page=2`. Прямая ссылка, перезагрузка страницы и кнопки браузера «Назад» / «Вперёд» восстанавливают это состояние. Изменения в интерфейсе обновляют адрес; остальные параметры URL и hash сохраняются.

Пустые поисковые параметры и `page=1` опускаются. Без `q` жанр и страница сбрасываются. Некорректный номер страницы заменяется на первую; номер за пределами выдачи — на последнюю доступную после успешного поиска. Жанр сопоставляется без учёта регистра и записывается в URL с названием из API; неизвестный жанр сбрасывается после успешного ответа. Во время загрузки или ошибки жанр и страница из ссылки сохраняются.

## Проверки

```sh
npm run check
```

`check` выполняет Biome и production-сборку.

Отдельные команды:

- `npm run lint` — Biome: код, форматирование, импорты.
- `npm run lint:fix` — безопасные исправления Biome.
- `npm run format` — форматирование.
- `npm run build` / `npm run preview` — сборка / локальный просмотр сборки.

Соответствие `ARCHITECTURE.md` и `AGENTS.md` агент проверяет самостоятельно вручную при каждой задаче: разделение View/Presenter, структуру и импорты, состояние, UI kit, циклы, декомпозицию и лимит 120 строк после форматирования.

## Структура и правила

Все изменения должны соответствовать [ARCHITECTURE.md](./ARCHITECTURE.md). Постоянные инструкции для агентов находятся в [AGENTS.md](./AGENTS.md).

Все функции, включая компоненты, Presenter, хуки и обработчики, объявляются стрелочными через `const`.

Вложенные тернарные выражения запрещены в Biome (`style.noNestedTernary: error`).

Произвольные значения и свойства Tailwind запрещены правилом Biome `nursery.noTailwindArbitraryValue: error`. Строки классов вне JSX, в том числе в Presenter и словарях вариантов, определяются через `tw(...)` из `src/app/ui-kit/tw.ts`, чтобы Biome проверял их литералы. Произвольные варианты и модификаторы встроенное правило не проверяет; они проверяются вручную.

Стили компонентов используют стандартные классы, палитру и брейкпоинты Tailwind CSS без произвольных значений и вариантов. Tailwind подключён через `@tailwindcss/vite`; базовые стили находятся в `src/index.css`, условные наборы классов подготавливаются в Presenter. В простом UI kit без собственной логики выбор вариантов оформления и объединение классов разрешены во View по разделу 6 `ARCHITECTURE.md`. Отдельный `tailwind.config.js` не требуется.

- `src/app/App.tsx` / `usePresenter.ts` — композиция страницы и флаги отображения блоков.
- `src/app/SearchField`, `Results`, `Feedback` и вложенные фильтры/пагинация — прикладные компоненты; их Presenter подписываются на нужные данные Redux и отправляют actions без передачи через промежуточные компоненты.
- `src/app/Results/ShowCard` — карточка, получающая данные шоу через props; UI kit также использует props и не зависит от Redux.
- `src/app/ui-kit/Button` — общий примитив кнопки без бизнес-логики и Presenter по разделу 6 `ARCHITECTURE.md`.
- `src/api/tvmaze` — HTTP, нормализация и типы API.
- `src/store` — Redux store и типизированные хуки. Строка поиска, выбранный жанр, страница, результаты, статус и ошибка хранятся в `search`; локальной копии прикладного состояния в App нет.
- `src/store/search` — slice поискового состояния, общие мемоизированные селекторы, атомарное восстановление параметров из URL и middleware запросов с debounce, отменой и защитой от устаревших ответов.
