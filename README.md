# Showroom / SA

Поиск сериалов и шоу в TVmaze. React, Redux Toolkit, TypeScript, Vite и Tailwind CSS; собственный слой запросов без `useQuery`. Интерфейс адаптируется к телефону и управляется с клавиатуры.

## Запуск

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173`). Для запросов и постеров нужен доступ к интернету.

## Как работает поиск

- Заголовок Showroom и поле поиска видны всегда. Изначально список пуст, запросы не отправляются.
- После 350 мс без нового ввода запрос передаётся в TVmaze. Фильтрацию названия и порядок совпадений определяет API.
- Предыдущий запрос отменяется при изменении поискового запроса, очистке или повторной попытке. Поздний ответ не заменяет актуальный; тайм-аут — 12 секунд. Пробелы по краям не вызывают повторный запрос.
- Уникальные жанры собираются из всей выдачи. Фильтрация жанра выполняется перед разбиением по 3 шоу на страницу.
- Изменение запроса или жанра сбрасывает страницу. «Все жанры» снимает фильтр, повторный клик по выбранному жанру также его снимает.
- Обработаны загрузка, отсутствие совпадений, ошибки сети/API, повтор запроса, отсутствующие и повреждённые постеры. HTML из описаний преобразуется в обычный текст.

## Проверки

```sh
npm run check
```

`check` выполняет Biome и production-сборку.

Отдельные команды:

- `npm run lint` — Biome: код, форматирование, импорты.
- `npm run lint:fix` — безопасные исправления Biome.
- `npm run format` — форматирование.
- `npm run build` / `npm run preview` — сборка / локальный просмотр сборки.

Соответствие `ARCHITECTURE.md` агент проверяет самостоятельно вручную при каждой задаче: разделение View/Presenter, структуру и импорты, состояние, UI kit, циклы, декомпозицию и лимит 120 строк после форматирования.

## Структура и правила

Все изменения должны соответствовать [ARCHITECTURE.md](./ARCHITECTURE.md). Постоянные инструкции для агентов находятся в [AGENTS.md](./AGENTS.md).

Все функции, включая компоненты, Presenter, хуки и обработчики, объявляются стрелочными через `const`.

Вложенные тернарные выражения запрещены в Biome (`style.noNestedTernary: error`).

Произвольные значения и свойства Tailwind запрещены правилом Biome `nursery.noTailwindArbitraryValue: error`. Строки классов вне JSX, в том числе в Presenter и словарях вариантов, определяются через `tw(...)` из `src/app/ui-kit/tw.ts`, чтобы Biome проверял их литералы. Произвольные варианты и модификаторы встроенное правило не проверяет; они проверяются вручную.

Стили компонентов используют стандартные классы, палитру и брейкпоинты Tailwind CSS без произвольных значений и вариантов. Tailwind подключён через `@tailwindcss/vite`; базовые стили находятся в `src/index.css`, условные наборы классов подготавливаются в Presenter. В простом UI kit без собственной логики выбор вариантов оформления и объединение классов разрешены во View по разделу 7 `ARCHITECTURE.md`. Отдельный `tailwind.config.js` не требуется.

- `src/app/App.tsx` / `usePresenter.ts` — интерфейс и единая UI-точка доступа к поисковому состоянию Redux; подготовка данных и обработчиков для дочерних компонентов.
- `src/app/SearchField`, `Results`, `Feedback` — приватные дочерние компоненты приложения с собственными Presenter.
- `src/app/ui-kit/Button` — общий примитив кнопки без бизнес-логики и Presenter по разделу 7 `ARCHITECTURE.md`.
- `src/api/tvmaze` — HTTP, нормализация и типы API.
- `src/store` — Redux store и типизированные хуки. Строка поиска, выбранный жанр, страница, результаты, статус и ошибка хранятся в `search`; локальной копии прикладного состояния в App нет.
- `src/store/search` — slice поискового состояния и middleware запросов с debounce, отменой и защитой от устаревших ответов.
